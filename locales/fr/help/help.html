Le serveur de statistiques répond au rapport de ce Dotclear avec les règles de compatibilité de la prochaine version de Dotclear. La vérification compare le code des plugins et thèmes installés à ces règles, sur ce serveur seulement.

Résultats
Alerte : le module cassera avec la prochaine version de Dotclear. Remarque : le module utilise quelque chose d’obsolète, il cassera plus tard ou dans certains cas. Chaque élément trouvé indique le fichier, la ligne et ce qu’il faut utiliser à la place.
Limites
La vérification est une aide, pas une garantie : certains usages ne peuvent pas être trouvés en lisant le code. Prévenez l’auteur d’un module en alerte, ou cherchez une nouvelle version.
