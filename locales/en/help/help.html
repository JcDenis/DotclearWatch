The statistics server answers the report of this Dotclear with the compatibility rules of the next Dotclear version. Checking compares the code of the installed plugins and themes with these rules, on this server only.

Results
Alert: the module will break with the next Dotclear version. Notice: the module uses something deprecated, it will break later or in some cases. Each finding gives the file, the line and what to use instead.
Limits
The check is a help, not a guarantee: some uses can not be found by reading the code. Tell the author of a module in alert, or look for a new version.
